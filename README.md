# xrwvm-fullstack_developer_capstone

## Project Name: Best Cars Dealership - Full Stack Application Development Capstone Project

**Repository name:** xrwvm-fullstack_developer_capstone

**Project name:** Best Cars Dealership

### Description
Best Cars is a national car retailer with dealerships across the United States. This full stack web application lets users:

- View the list of dealerships, and filter them by state
- View the details and reviews of a dealership
- Sign up, log in and log out
- Post a review for a dealership (logged-in users), with sentiment analysis of each review

### Technologies
- Django (Python) back end with SQLite for users, car makes and car models
- Node.js / Express microservice with MongoDB for dealers and reviews
- React front end
- Sentiment analyzer microservice deployed on IBM Cloud Code Engine
- Docker, Kubernetes and GitHub Actions (CI/CD)
